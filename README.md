# Silk Road — Home First, Then We'll See

一個以 Three.js 製作的 3D 互動小說旅程，沿 Rei 的絲路路線探索 Merv、波斯山口、泰西封、安條克與歸返敦煌。

## 操作

- 使用 `CONTINUE` / `PREVIOUS` 或點擊場景地標切換七個故事節點。
- 點擊互動按鈕探索玻璃工坊、尋路者印記、波斯通商文件、泰西封織布及安條克海景。
- 拖曳旋轉視角、滾輪縮放，亦可平移場景；支援日光切換與可選風聲。
- 頁面引用 Three.js 與 OrbitControls CDN，需網路連線；敦煌照片素材與頁面一同提供。

## 故事範圍

原稿附件包含 Chapter Two 至 Chapter Seven，因此互動版從 Merv 開始，不補寫缺少的 Chapter One。Merv、波斯山口、泰西封及安條克以敘事用程序化 3D 場景表示，並非考古復原模型。
